Política de Privacidad de La Historia que Suena

Última actualización: 26 de septiembre de 2026

La Historia que Suena es una aplicación diseñada para identificar canciones y ofrecer información histórica y documental relacionada con las obras musicales identificadas.

1. Uso del micrófono

La aplicación solicita acceso al micrófono únicamente cuando el usuario utiliza la función de identificación musical.

El sonido captado se utiliza temporalmente con el propósito de reconocer una canción. La aplicación no utiliza el micrófono para grabar conversaciones ni para realizar escuchas permanentes en segundo plano.

La Historia que Suena no conserva deliberadamente grabaciones de audio del usuario una vez terminado el proceso necesario para la identificación musical.

2. Identificación de canciones

Para realizar el reconocimiento musical, la aplicación puede utilizar servicios de reconocimiento de música proporcionados por terceros.

Durante este proceso pueden transmitirse temporalmente datos técnicos o fragmentos derivados del audio necesarios para realizar la identificación, de acuerdo con el funcionamiento del servicio de reconocimiento utilizado.

La finalidad exclusiva de este proceso es determinar información relacionada con la canción, como el título de la obra y, cuando sea posible, el intérprete.

3. Información histórica de las canciones

Después de identificar una canción, determinados datos relacionados con la obra, como el título y el intérprete identificado, pueden enviarse a servicios externos para recuperar, elaborar o complementar información histórica y documental.

Estos servicios pueden incluir infraestructura de procesamiento en la nube, bases de datos y herramientas de inteligencia artificial utilizadas para generar o recuperar información relacionada con la obra musical.

La aplicación no necesita enviar el nombre, teléfono, dirección, contactos u otros datos personales del usuario para realizar esta consulta.

4. Información almacenada en el dispositivo

La aplicación puede guardar localmente determinados resultados, identificaciones, fichas musicales o historial necesario para ofrecer sus funciones y permitir al usuario consultar información previamente obtenida.

Esta información se utiliza exclusivamente para el funcionamiento de la aplicación.

5. Datos personales

La Historia que Suena no requiere que el usuario cree una cuenta para utilizar sus funciones principales.

La aplicación no solicita deliberadamente datos personales tales como nombre, domicilio, número telefónico, lista de contactos, fotografías personales o información financiera para realizar la identificación de canciones.

6. Servicios de terceros

La aplicación puede utilizar servicios tecnológicos de terceros para funciones como reconocimiento musical, procesamiento de información, alojamiento, generación de contenidos y otros servicios necesarios para su funcionamiento.

Estos proveedores pueden procesar información técnica necesaria para prestar sus servicios de acuerdo con sus propias políticas de privacidad y condiciones de uso.

7. Seguridad

Se aplican medidas razonables para limitar el acceso y el tratamiento de la información utilizada por la aplicación únicamente a lo necesario para prestar sus funciones.

No obstante, ningún sistema de transmisión o almacenamiento electrónico puede garantizar una seguridad absoluta.

8. Menores de edad

La Historia que Suena no está diseñada específicamente para recopilar información personal de menores de edad.

9. Cambios a esta política

Esta Política de Privacidad podrá actualizarse cuando cambien las funciones de la aplicación, los servicios tecnológicos utilizados o los requisitos legales y de las plataformas de distribución.

La fecha de la última actualización aparecerá siempre al inicio de este documento.

10. Contacto

Para preguntas relacionadas con esta Política de Privacidad, los usuarios podrán utilizar la información de contacto del desarrollador publicada en la ficha oficial de La Historia que Suena en Google Play.
