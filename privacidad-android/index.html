Política de Privacidad de La Historia que Suena (versión Android)

Última actualización: 15 de octubre de 2026

La Historia que Suena es una aplicación diseñada para identificar canciones y ofrecer información histórica y documental relacionada con las obras musicales identificadas. Esta política aplica a la versión para Android, publicada por Enrique Forzan Aburto.

1. Uso del micrófono

La aplicación solicita acceso al micrófono únicamente cuando el usuario utiliza la función de identificación musical. El sonido captado se utiliza temporalmente para reconocer una canción. La aplicación no usa el micrófono para grabar conversaciones ni para escuchar de forma permanente en segundo plano, y no conserva deliberadamente grabaciones de audio una vez terminado el proceso de identificación.

2. Identificación de canciones

Para reconocer la música, la aplicación utiliza servicios de reconocimiento proporcionados por terceros (ShazamKit). Durante este proceso pueden transmitirse temporalmente datos técnicos o fragmentos derivados del audio, de acuerdo con el funcionamiento de ese servicio. La finalidad exclusiva es determinar el título de la obra y, cuando sea posible, el intérprete.

3. Información histórica de las canciones

Después de identificar una canción, el título y el intérprete se envían al servidor de la aplicación y a servicios externos (infraestructura en la nube y herramientas de inteligencia artificial) para elaborar la información histórica. No se envían a estos servicios el nombre, teléfono, dirección ni contactos del usuario.

4. Cuenta de usuario

En la versión para Android, el usuario inicia sesión con su cuenta de Google. Para ello se recibe y se guarda su dirección de correo electrónico y un identificador de cuenta. La aplicación no solicita nombre, domicilio, teléfono, contactos ni fotografías.

5. Compras, suscripciones y saldo

Cuando el usuario adquiere una suscripción o una recarga, el pago lo gestiona únicamente Google Play; la aplicación no recibe datos de tarjeta ni de facturación. Se envía al servidor de la aplicación el identificador del producto y el código de compra, que se valida con Google. El servidor conserva el historial de compras, el saldo de identificaciones disponibles y el número de identificaciones utilizadas por cada cuenta. Esta información se usa únicamente para acreditar compras y controlar el uso del servicio, y no se comparte con terceros con fines publicitarios.

6. Información almacenada en el dispositivo

La aplicación puede guardar localmente resultados, fichas musicales o historial necesarios para sus funciones y para que el usuario consulte información previamente obtenida.

7. Eliminación de cuenta y datos

El usuario puede solicitar la eliminación de su cuenta y de los datos asociados siguiendo las instrucciones de: https://eforzanaburto-dotcom.github.io/la-historia-que-suena-privacidad/eliminar-cuenta/

8. Servicios de terceros

La aplicación puede utilizar servicios de terceros para reconocimiento musical, inicio de sesión, pagos, alojamiento y generación de contenidos. Estos proveedores procesan la información necesaria según sus propias políticas de privacidad.

9. Seguridad

Los datos se transmiten mediante conexiones cifradas y se aplican medidas razonables para limitar el acceso a lo necesario. Ningún sistema puede garantizar una seguridad absoluta.

10. Menores de edad

La aplicación no está dirigida a menores de edad ni recopila deliberadamente información de ellos.

11. Cambios a esta política

Esta política podrá actualizarse cuando cambien las funciones de la aplicación, los servicios utilizados o los requisitos legales. La fecha de la última actualización aparecerá siempre al inicio.

12. Contacto
